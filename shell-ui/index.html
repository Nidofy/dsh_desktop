文件快照与恢复

保护指定文件的原始内容。可手动记录，也可为工作区启用每轮自动快照，再按文件预览恢复。在下方选择要保护的文件。

快照保存在本机，可跨连接使用。

设置文件范围 / 新建快照

1–128 个文件，每个最多 8 MiB，合计 32 MiB；二进制可保存。可预先列出尚不存在的文件，但父目录必须已存在。自动范围仅匹配会话的同一工作区，不递归包含其他工作区；变更从下一轮生效。

浏览工作区并选择文件

使用上方填写的工作区。按目录浏览并勾选后加入范围；不会递归选择，也不会自动启用快照。链接、Git/Hg 元数据和不可读项目不列出。

自动快照默认关闭。每轮开始前采集，结束后封存；启用保护后，开始快照失败或超时会停止该步骤，不自动重试。最多保留 20 份 / 256 MiB，达到上限后需自行归档或清理。

归档 / 校验 / 导回快照

归档包含原始源码、工作区路径和恢复前备份，仅保存到本机固定磁盘。导出后原快照保留；导回不会修改工程，仍需单独预览并恢复。

快照备份与恢复记录

查看历史备份和恢复记录。恢复文件前请刷新预览。

本机存储管理

查看共享工作区与旧版目录中的诊断、操作记录、比较基线、导出文件和快照。原生会话、项目文件、连接凭据与操作信任不在清理范围。

本机存储总览

统计桌面受管目录，包含配置回退后隐藏的旧连接和临时文件。不包含原生会话、工程文件或系统日志。

默认 2048 MiB（2 GiB），可设 256–65536 MiB。降低上限不会删除已有记录或撤销运行中任务的预留；额度不足时，新操作需等待释放、归档清理或提高上限。

时间范围只用于本次扫描，不会自动定期清理。

扫描只读取本机元数据，不发送模型请求。

未引用的连接凭据

检查 Windows 凭据管理器中本应用创建的连接凭据。当前配置、回退备份、暂存配置和正在运行的连接所引用的凭据，以及最近 24 小时写入的凭据均保留。只显示编号和写入时间。

扫描在本机完成，不读取或显示密钥内容。
