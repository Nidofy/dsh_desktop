# 每棒交接模板

复制必要内容到 NEXT_HANDOFF.md；同份简短记录存 ../handoffs/relay-NN-sol.md 或 relay-NN-astra.md。每棒必须同时生成 NEXT_PROMPT.txt，并在最终回复贴出其内容。

- 当前模型及下一模型（实际客户端不提供的标识不得猜测）：
- 实际工作目录/分支；未提交与来源目录改动：
- 本棒完成的行为、文件与必要接口：
- 实际命令、退出码、覆盖范围及日志路径：
- 未完成功能与真正阻塞；另列延期发行资格，后者不能作为本阶段停点：
- 转交理由：具体失败/设计决定/外部限制；无技术触发时同模型续做：
- 下一棒第一项动作、少量可观察的完成条件、允许修改范围、完成后立即进入的后续任务：
- 已解决的 Astra 问题及无需重复验证的证据：
- 数据/权限/迁移限制：
- 可直接发送的下一棒完整 prompt：

不要求提交号、不复制整段聊天、不因写交接再跑已通过测试。历史 review 保留，不能由文档作者伪造验收。

只记录本棒增量，历史详细限制和证据链接原文件；未验证资格与真正阻塞分开，不把所有 PARTIAL 当作停止理由。不把历史单棒仅 T20 限制带入新任务；当前范围内必要共享接线、验证和最小登记由当棒完成。
