## 接口覆盖与消费者

官方定义只读复用：refs 的 resolve/describe/set/unset，records 的 read/describe/list/modify/delete 全部实现。modifyRecord 的 mutate 持有跨进程文件锁，读当前磁盘状态，返回 undefined 保持原记录；回传和回调输入与内部通知状态分离。整个文档和 UTF-8 metadata 计入配置限额。相同值的已提交 set/modify 也发通知；无操作 unset/delete 不发。官方通知 dispatcher 保留 contained listener 与 INVARIANT 语义。

引用保持 inherited process > encrypted managed > project dotenv > user dotenv；非空 inherited 为只读，空值为 absent；managed 不可读时先拒绝，不能以 dotenv 或最后缓存伪造成功。记录没有环境层，空 api-key record 保持 configured=true。部署选择均为显式 Config；当前 provider 的 source 标识为 `windows-dpapi`，metadata 永不包含 value。

已核对官方消费者：T01 runtime.ts 的真实 credentialRef adapter；llm-pi-ai auth.ts 的 provider records/refresh/list；authorization 的 grant 提交；deepseek-account-platform 的 ref/record 读改写。T02 替身测试覆盖通用接口，真实 Loader/T01 测试消费正式 installConnections。没有真实第三方 OAuth/模型计费调用，未声称所有产品消费者已通过认证联验。此交付是完整 provider 实现；**生产 provider 仍未替换**，W03 前不能宣称全局存储已切换。

## 数据、迁移与回退

新派生格式 version=1，与官方 `.credentials.yaml` version=1 和 Session 格式无关。磁盘外层只有 version、namespace、DPAPI ciphertext；解密文档包含 revision、refs、records、migration receipt。应用/profile/规范 home 同时参与目录命名和 DPAPI 熵；同 home 别名不会各自建立 writer 锁。CurrentUser 保护依赖 OS 用户，熵不阻挡同用户恶意代码；[Microsoft DPAPI 文档](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata) 是平台语义依据。512 KiB 是测试部署 document limit，240 KiB record 和历史 256 KiB probe 均不是 Windows 最大容量声明。

迁移只接收 Host 显式选定的官方版本 1 **副本**，目标需为空：encrypt candidate → decrypt/compare readback → journal → atomic current → verify selected operation → secret-free receipt → remove journal。原文件始终不删不改；没有自动扫描或迁移真实 home。未记录 journal 的候选不被选定。prepared journal 阻止普通写入；读取仍只读 current。选定后 receipt 写失败可通过原 UUID inspect 看到真实已提交，不自动重放。显式 recover 使用候选或已选定结果，不重读已变动来源；重复原操作查询/恢复幂等。undefined inspect 只表示未证明 commit，不能授权重放外部副作用。

回退使用保留的官方来源副本和旧发行配置；不承诺旧程序读取 DPAPI 新格式。普通 metadata/list/receipt 不含秘密；不提供一般秘密导出 API。R 的通用备份/导出还必须排除该私有存储目录和来源副本，不能把“密文”视为可公开资料。原子工具不 fsync 文件/目录，未承诺断电持久性。仍可能存在 live PID 重用而保守等待旧锁的情况；不自行删除未知锁。

## 生命周期、失败和恢复

provider activation 不读取平台秘密；后端拒绝仍可加载服务并由 T01 标记逐修订 backend-unavailable。修复后下一操作重新读平台，没有 stale secret 返回。所有读写和 polling 在唯一队列；writer 锁覆盖整个异步 mutate。卸载先拒新操作、停 timer，再等待已准入工作排空；已经开始的 commit 可完成，但关闭后不再发布通知。无自动重放外部授权刷新。标准写入先验证加密回读再选定，选定后不再调用可能失败的 decrypt 来把提交误报为未发生。

存储/加密/解析错误通过固定安全 code 返回，不附原始异常、stdout/stderr、源行或秘密值。原官方通知 dispatcher 的第三方监听器错误策略未改变；T02 事件本身仅传引用或 record key。真实 helper 使用当前 Windows 用户，未调用 Credential Manager 或读取用户的现有秘密条目。
