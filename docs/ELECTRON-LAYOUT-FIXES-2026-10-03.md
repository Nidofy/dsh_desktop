# Electron 环境信息与角色侧栏调整（2026-10-03）

## 布局决定

环境信息从覆盖聊天的 `shell.overlay` 浮层移到参与正常布局的右侧栏。右栏宽 300 CSS px；中心区域在扣除官方左侧工作区和右侧文件面板后至少有 1040 CSS px 时显示，保证聊天至少有 740 CSS px。打开侧边栏或缩小窗口会自动隐藏右栏，空间恢复后自动显示。环境卡片可折叠，下方角色区伸展填充；高度不足时右栏内部滚动。窄窗口仍可通过「应用」菜单访问工程工作台和个人扩展。

卡片跟随当前会话显示工作目录、Git/Hg 仓库、分支和增删行数，连接与工程操作通过已有受校验的原生入口打开。未打开会话时显示提示，未检测到仓库时如实显示，不生成虚构的 PR 或来源记录。

## 图 4 的判断与 Live2D 扩展

仅凭截图能确认角色立绘、对话卡片、表情按钮和主题装饰的组合，不能确认其采用 Live2D、序列帧还是多张静态立绘。图 5 可以通过独立列和上下 flex 布局实现，角色渲染方式不需要影响聊天或环境面板。

当前使用已有「小鲸」透明立绘和构建、产物、快照、桌宠入口。`nidofy.companion` 是独立单插槽，后续 Live2D 插件可替换默认立绘，继续使用同一角色容器；通过 `active` 接收可见状态，通过 `sessionId` 获取当前会话。区域因宽度不足隐藏或文档进入后台时 `active=false`，渲染器应暂停动画；卸载时应释放动画循环、事件监听、图形资源。当前未捆绑 Live2D SDK、模型，也没有把静态立绘描述为 Live2D 成品。

## 图标与背景

Windows 程序、窗口及托盘使用旧 Tauri 的 `src-tauri/icons/icon.png`、`icon.ico`，背景使用旧 `shell-ui/wallpaper.png`。资源按字节复用；背景保持原实现的 contain 居中、24px 内边距、14% 不透明度、不接收鼠标事件，并在强制高对比度模式下隐藏。官方侧栏和欢迎页的 DeepSeek 标志延续旧 Tauri 截图表现。默认官方发行配置继续使用其原图标。

## 后续跟随官方升级

仍保持插件优先。环境卡片、角色展示、功能入口、背景和样式均归私有 desktop-extras 插件；官方布局仅新增可选 `shell.accessory` 插槽、主面板包装和尺寸容器，不修改模型引擎。没有插件占用时聊天使用全部中心宽度。原生图标选择复用发行版配置。

升级时检查 ui-layout 插槽声明、容器名称与实际宽度、官方侧边栏开关、会话引用、主题变量和资源路由；运行本次响应式检查与插件卸载检查。官方出现等价插槽后，应删除局部布局补丁。具体路径与退出条件记在 `electron/migration/m4-layout-fixes/patch-ledger.json`。
