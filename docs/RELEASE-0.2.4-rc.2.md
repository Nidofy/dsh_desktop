# 0.2.4-rc.2：可靠切换与恢复

固定 DSH 0.1.5-rc.2、Node 24.16.0、WebView2 153.0.4234.48。此候选承接 0.2.0 / 0.2.3 功能和既有宠物启停/退出修复，没有覆盖旧发布目录，也没有推送或发布 GitHub Release。

## 功能

- 配置跨文件加密事务、冲突检测、受控遗留写锁恢复；连接预检和就绪后提交，失败保留旧默认连接并尝试恢复原运行定义。
- 应用、重启、菜单/托盘重启、维护与显式工作区修复统一检查任务。提供待应用、原生取消和显式停止；确认绑定引擎及配置代次，旧确认不可复用。
- 分层健康与有界后台查询，快照保护未确认时拒绝开始受保护步骤；固定类别结构化故障。
- 工作区迁移版本边界、一次性重复目录修复；按策略加载缓存桥并在不支持时拒绝应用。
- 模型能力来源与路由绑定，旧配置迁移保留，新未知自定义模型不猜测推理档位。
- 候选环境创建、独立运行、目录入口、删除及检查点存档。数据、默认工程、凭据引用、进程锁相互隔离。
- 修复桌宠浏览器计时器调用错误、快速拖动起点丢失和气泡测量造成的位置回跳。正常拖动及重启恢复已在原生窗口验证。

详细实现和前两批验证见 [实施记录](IMPLEMENTATION-0.2.4.md)。

## 边界

- 这是 RC 候选，不表示所有内网网关与硬件现场均完成验收。
- 固定引擎没有可靠的全局任务准入冻结接口，因此待应用后仍需显式确认停止；不宣称无损自动热切换。
- 检查点是未挂载存档；自动升级、挂载旧工程、晋升与回退编排属于后续组合升级工作。复制前还须停止独立 CLI 等其他写入者。
- 无标签或身份不明的旧设置锁保持原状；未模拟真实硬件断电。默认结构化日志不包含原始配置/模型输出，本轮没有扩展任意原始载荷的调试采集。
- 跨屏混合 DPI、真实触摸/手写笔硬件、长期性能、干净虚拟机离线和企业现场网络尚需现场记录。鼠标原生窗口检查与触摸/手写笔纯状态机测试分别记录。
- 候选删除的路径/链接/互斥逻辑有原生测试，未通过 GUI 删除现场数据；资源与模型服务本轮未升级。
