# DSHDesktop 0.2.0

本版作为日常使用基准，包含 RC2 验证期间的启动恢复、连接管理、工作区环境浮窗和辅助页面外观修正。按用户要求，实际内外网验证与后续开发并行；发现具体问题后修复，不等待现场检查矩阵全部结束才交付。

## 本版功能

- DeepSeek 官方连接、已知提供方预设和自定义提供方；可编辑地址/协议、删除连接、正确显示已应用状态。所有连接共享工作区与会话。
- 修复重复工作区目录造成的启动失败；迁移前备份，保留会话和归档。
- Codex 式环境浮窗：默认关闭、按需打开、窄窗口自动收起，不注册右侧栏；可在 DSH 插件设置中启停。支持 Git 分支、比较、暂存区提交和显式推送，Hg 状态与变更查看。
- 设置页分类、诊断导航排版、统一 DSH 主题与字号；清理早期配色和过时操作说明。
- 原生任务状态、Git/Hg 变更基线、差异追加草稿、项目构建/测试、产物、快照和恢复、后台提醒、配置/凭据/存储维护。
- 双 API 格式独立识图配置，缓存键与标记设置、前缀稳定化、缓存探针、诊断导出、A/B 比较与环境自检。

## 升级使用

从托盘退出旧版，运行新完整目录中的 `DSHDesktop.exe`，保留 `resources`。程序使用原有 `%LOCALAPPDATA%\DSHDesktop` 数据，连接与会话无需重新创建；旧验证目录保留。本轮不制作 ZIP。

具体交付目录、构建 ID、文件校验与验证状态由 [stable-0.2.0.json](evidence/stable-0.2.0.json) 记录。EXE、随包运行时和许可证清单均保留在交付目录；使用 `Verify-DSHDesktop.ps1` 检查完整性。

## 验证范围与后续修复

本机构建门禁覆盖 Rust 测试、双协议模型/工具/切换、Git/Hg、代理/CA、快照、缓存前缀、识图、自检、诊断与异常恢复。交付流程另执行实际目录离线启动、API 失败路径、原生进程与完整性检查。最终结果以构建回执和本版证据文件为准。

当前真实使用反馈为 RC2 theme 验证版「基本正常」。真实内外网缓存收益、企业环境、干净 Windows 10/11、系统通知和文件对话框、大型工程仍持续收集结果；这些项目不标作已通过。记录方式见 [持续现场验证](ACCEPTANCE-0.2.0.md)。

现有能力边界：Hg 暂无写操作；在线 PR 未接入；来源展示连接与根目录 AGENTS.md/CLAUDE.md；切换不同连接需重载后端。程序未签名。固定依赖不会自动更新。
