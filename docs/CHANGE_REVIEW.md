# 变更查看与比较基线

入口：Help → 会话诊断 → 变更查看；任务恢复页也可直接打开该工作区的变化。只读使用本机 Git/Hg，不执行提交、checkout、revert、拉取或推送。

## 日常操作

- 输入工作区绝对路径。工作区位于子目录时显示所属仓库根目录，比较范围是该仓库。
- 不选基线：查看当前未提交文件状态。Git 状态保留两列 XY，并分别提供「版本 → 当前文件」「版本 → 暂存区」「暂存区 → 当前文件」。Hg 不提供 Git 暂存区视图。
- 记录当前基线，或开启「每轮任务开始前记录基线」。自动开关按连接和规范化仓库路径隔离，默认关闭，从下一轮开始生效；无需开启请求诊断采集。
- 选择基线后，可以查看基线到当前文件、版本到基线文件的差异。原有修改继续变化、已有但未继续变化、任务期间变化、无法准确比较分别标注。期间提交的新版本不会取代所选旧基线。
- 在 diff 区域选择所需片段后，可复制或展开「送入会话草稿」，载入并明确选择同一仓库中的主会话，检查本次选中片段后追加到原生输入框。打开、刷新、选择及追加都不会调用模型；由你审阅后手动发送。

## 选中差异送入草稿

- 只追加选中的片段，附带文件和比较范围说明；没有选择时不可操作，单次最多 64 KiB。不会把整份 diff 或整个文件作为隐式回退。切换文件、基线或比较方式后清除旧选择。
- 后端重新计算当前差异并校验预览 hash；变化后要求刷新重选。目标会话按规范化 Git/Hg 仓库根目录匹配，子目录会话可以选，其他仓库和子代理会话拒绝。候选每页扫描 50 个会话，可继续载入更多。
- 使用 DSH 原生会话输入接口和 `slash/input-insert-text` 的版本校验，只在末尾插入；已有文本、引用 chip、附件不会被整个草稿替换。正在提交、命令占用、不可编辑或已不在会话列表的目标会拒绝。
- 同源通道只广播随机票据，片段通过已鉴权本机接口领取；每份票据只能一个窗口领取。暂存最多 16 份、120 秒有效，不落盘、不导出。只有领取并写入后返回成功回执；丢失回执保持结果未知，不自动重放。
- 主界面未领取时，等待 10 秒后撤销尚未领取的票据；已经领取但回执未到则提示先检查原草稿。引擎退出后暂存消失，不在重启后自动补填。草稿本身由 DSH 原生机制管理。
- 追加完成定位目标会话并请求桌面聚焦。真实原生 DSH Web 输入框已验证；Windows Tauri 的跨窗口焦点仍需目标机验收。

「任务期间」实际指基线采集到本次读取，包含手工编辑和其他进程的工作；不标记为 AI 独占修改。自动基线记录原生 session ID 和轮次，每轮至多一次；它不推断多轮会话的业务任务边界，也不自动给子任务采集另一份基线。

## 基线范围和限制

基线包含版本、跟踪文件清单、已有变化的工作区内容/hash、Git 暂存内容 hash 和状态。干净文件仍引用 Git/Hg 中的原版本，**不是完整备份，也不是可直接撤销的快照**。本版本不提供恢复文件操作。仓库历史被删除、裁剪后，对应内容可能无法读取。

- 最多 10000 个路径；单个文件内容最多 2 MiB，一次基线的工作文件内容最多 16 MiB。
- 每连接最多保留 30 份基线、合计 128 MiB；超额删除最旧的本功能记录，不删除工作区文件。列表读取目前仍需解析保留的基线，大型基线历史的索引优化待后续。
- 基线不是文件系统原子快照：前后复查状态、版本、已采集内容和 index hash；检测到变动则标记覆盖不足。无法阻止同时运行的编辑器/其他任务写入，因此不提供独占归因保证。
- 自动采集使用 DSH 正式 `agent/pre-step` 等待链，落盘后才继续当前首个模型/工具步骤。15 秒总预算，失败、取消或超时不重试且不阻止任务；页面显示最近失败提醒。重启读取旧基线不会重跑任务或补采旧轮次。
- 链接、junction、子模块目录、特殊文件、大文件、无法读取的文件显示未知；不遍历仓库之外的链接目标。忽略文件不进入基线，重命名按旧路径删除/新路径新增查看。
- 文本预览合计最多 256 KiB、diff 计算 500 ms、结果最多 512 KiB。UTF-8 文本按 LF 比较；换行/权限变化可能没有文本 hunk。二进制、其他文本编码保留状态但不猜测内容编码。
- 当基线覆盖不完整时，所有任务归属保守显示未知。原生 VCS 状态仍可单独查看。冲突文件可能没有可读取的 stage 0，显示无法准确比较。

## 只读执行与隐私

所有 VCS 参数使用 argv，不拼接 shell。可执行文件从绝对 PATH 项查找，不从工程当前目录隐式执行同名程序。进程环境只带基础系统字段，不转交模型密钥；命令有 10 秒超时和输出上限。

Git 禁用 fsmonitor、外部 diff/textconv，读取配置后禁用声明的 clean/process filters，避免只读状态检查触发仓库配置的外部程序。这也意味着依赖过滤器的仓库（如 LFS）可能显示原始指针/原始字节差异，不能视作过滤器还原后的精确内容比较。

Hg 使用 `HGPLAIN`、空 `HGRCPATH` 和 `HGRCSKIPREPO`，不加载仓库 hooks/extensions；需要扩展才能读取的特殊仓库可能不支持。依据：[Mercurial 官方自动化说明](https://www.mercurial-scm.org/help/topics/scripting)。Windows Mercurial 保留 ANSI 文件系统编码，使用 Windows PowerShell 5.1 读取系统代码页后严格解码路径；在当前中文系统代码页上实际验证通过。

基线保存在当前连接 DSH_HOME 的 `desktop-changes`，包含内部文件内容和路径，属于本地工程数据，不并入去标识诊断导出。页面复用原生本机鉴权和同源写请求校验，没有外部下载或上传。

## 验证

- `node tests/change-review.mjs`：真实 Git、已有/期间/提交后变化、Git stage-only 变化、中文和字面路径、链接/大小限制、禁用仓库外部 filter、持久化、保留上限及原生 hook 契约。
- `node tests/change-review.mjs --hg`：本机额外使用 `.build/hg-test-venv` 中隔离安装的 Mercurial 7.2.2，验证中文路径、相同基线语义以及禁用仓库 hook；不安装到用户全局 Python，不随产品分发测试环境。
- `node tests/change-review-wire.mjs`：真实捆绑 DSH + 合成本机模型，验证两轮基线先于首个模型 HTTP 请求落盘、鉴权、同源保护、选中 diff 和不额外调用模型。
- `node tests/change-draft.mjs`：目标仓库约束、过期差异、选中内容、一次领取、未知回执、票据限额/过期/取消，以及原生输入接口的草稿/引用/附件保留和不可编辑拒绝。`change-review-wire.mjs` 同时验证真实选片、晚到文件修改拒绝、重复领取拒绝及取消。
- `change-review-wire.mjs --draft-browser` 可保留隔离实例供浏览器验证，按 Enter 结束；结束时断言模型请求没有增加。浏览器实际验证了旧草稿与文件引用节点保留、选择片段追加，以及不自动发送。临时登录地址仅在 `.build` 测试目录，不用于产品文档。
- `node tests/observability-wire.mjs`：OpenAI/Anthropic 既有模型、工具沙箱、缓存、取消/恢复、隐私和最终请求一致性回归。
- 浏览器 fixture 使用真实 Git 和变更服务，验证基线选择、原有修改继续变化、任务 diff、自动开关，以及 DSH 深色/浅色和 17px 字号。此项不等同原生 Tauri 窗口的完整验收。

真实大型 Git 工程、Hg 求解器工程、特殊仓库扩展、并发编辑下的体验和完整原生窗口验收仍待目标环境测试。
