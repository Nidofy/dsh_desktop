## 首批已实现

### 配置事务

源码：runtime-src/settings-sync.mjs、settings-transaction.mjs、settings-protection.mjs。

先用独立数据复现“新 settings.yaml + 旧修订标记”的中断状态，确认后续 B→A 会恢复错误的 B 原始配置。复现目录 .build/settings-gap-KtM4sB，未接触真实用户配置。

新增事务覆盖 settings.yaml、desktop-settings-revision.json 和 desktop-experiment-baseline.json。先生成并持久化加密事务，逐文件原子写入、刷新及核对，再移除事务。启动在同一原生设置锁内恢复未完成事务，然后计算新的连接变更。已经写好的文件不重复改写；无法解释的文件指纹变化明确报冲突。

事务只允许三个固定文件名，每文件上限 2 MiB，事务文件上限 24 MiB。使用 Windows CurrentUser DPAPI 加密；固定本机 Windows PowerShell、无 profile、窗口隐藏、超时和输出限额、通过私有 stdin/stdout 传输，不在命令行或明文日志中存储恢复载荷。其他平台或加密不可用时拒绝写入，没有明文回退。此保护与诊断 HMAC 密钥独立，不受重置诊断密钥影响。

保留旧修订标记兼容；新标记区分字段缺失与显式 null，恢复原提供方和默认选择时使用该存在性信息。原有配置备份仍保留，其现有本地存储策略本批没有扩展为全量加密备份系统。

新增独立错误分类：配置冲突、恢复记录不可读/无法解密、原生写锁占用。默认错误信息不带原始设置或解密异常文本。

### 可选缓存桥

源码：runtime-src/desktop-cache-key-bridge.mjs、host.mjs。

根据当前桌面连接 patch 决定是否装载独立缓存键桥。原生策略不读取、不校验或修改适配器源码。off/session 都需要桥：off 也会改变最终请求。需要桥时仍校验完整 SHA 和精确锚点，失败拒绝启动，不放宽匹配、不假装生效。

完整构建中的已知提供方回归暴露了旧逻辑仅识别 desktop-internal 的限制。现按 diagnosticState.managedProvider 限定作用范围，OpenAI 自定义与已知提供方都可以使用独立策略；其他原生提供方及已经退出桌面管理的路由不受影响，提供方身份仍进入缓存键隔离范围。已增加原生 ZAI 提供方最终请求上的 session key 验证。

不支持的格式/策略明确报错。策略尚未迁入完整版本适配目录，能力查询与连接应用前预检留待后续批次。启动前缓存错误仍可能发生在旧引擎已停止后；这一点必须由统一切换协调器继续解决，不能把本批当成安全热切换完成。

- 快照保护启用时，开始记录/确认失败会拒绝该模型步骤；只有明确收到 `DISABLED` 才按未启用作用域处理。不把超时当作已经获得保护。
- 历史迁移声明固定 `desktop-shared-workspace-v2`，只接受工作区 version=2。共享目录与所有待导入目录先做格式检查；未知格式在修复、备份和复制前拒绝，原文件字节不变。旧 version=1 迁移记录升级为 version=2，单独记录 `duplicate-path-v1` 修复完成状态，避免每次启动再次修复。保留停止引擎后的显式 `repairDuplicates` 入口参数，尚未接入设置按钮。

### 切换与恢复

- 私有宿主管道读取所有原生 agent 的运行、收件队列、审批状态，以及工程操作和主动验证任务数量。无 HTTP 控制入口，不传会话正文或模型输出。读取失败明确为未知。

- 待应用状态支持继续检查、原生取消全部任务及显式停止。取消请求不代表取消完成。确认凭证绑定引擎代次、PID、配置 revision，60 秒失效、一次消费；重复弹窗拒绝，旧代控制回执丢弃。

### 模型声明与候选环境

### 宠物位置

拖动改为窗口内 Pointer Events 捕获和宿主物理坐标移动：按下时记录位置，超过阈值后移动，每次只保留一个在途调用和最新移动请求，释放/取消后保存。气泡重新测量保持当前位置，拖动结束重新测量，避免回写旧坐标。保留单击/双击/长按仲裁，不使用全局钩子。是否通过真实窗口验收以发布记录为准，不能由纯状态机测试替代。

现场继续发现了两条纯状态机检查没有覆盖的问题，并完成修复：浏览器 Window 计时器被作为手势对象的方法调用，导致 WebView2 的 `Illegal invocation`；快速移动时，宿主在 IPC 到达后才读取起点，起点已经变成终点。现在默认计时器使用包装函数，拖动请求携带原始 pointerdown 客户区坐标，由宿主按窗口 DPI 转换为物理起点。已加入默认计时器接收者和 IPC 延迟时保留起点的回归。
