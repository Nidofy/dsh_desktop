# 工作区环境插件

本功能已加入 0.2.0 当前目标。采用 Codex 参考图中的浮动卡片与弹出菜单，不注册右侧栏页面，也不调用原生侧栏展开接口。

## 入口与显示

- DSH 设置 → 插件 → 工作区环境：启用或关闭，立即生效并持久保存。
- 面板默认关闭。已有会话使用标题栏右上角图标，新会话使用同位置的独立入口。
- 展开后，卡片悬浮在右上角，正文和输入框在其左侧留白；标题栏保持全宽。收起或禁用时释放留白。
- 中央可用宽度小于 980px，或窗口高度小于 560px 时自动关闭；窄窗口入口禁用。恢复宽度后由用户再次打开。
- 关闭或禁用会卸载面板，停止环境轮询。每次打开立即读取；展开时每 30 秒刷新，后台页面不轮询。
- 跟随 DSH 深色/浅色/系统主题。Esc 先关闭弹出菜单，再关闭卡片。

## 内容

环境信息卡片使用统一图标行：变更、本地、分支、提交或推送、Pull Request 状态、比较分支；下方为可折叠来源。加号菜单收纳构建、产物、快照、诊断、缓存与任务操作。来源当前展示桌面连接和工作区根目录中的 AGENTS.md / CLAUDE.md，不宣称覆盖全部上游加载来源。

Git 行数为已跟踪文件相对 HEAD 的变化；未跟踪文件在变更页查看。尚无首个提交时合并暂存和未暂存统计。读取不可用时保留已有仓库信息。Pull Request 未接入在线平台，入口显示未关联。

Git 支持搜索本地分支、创建并检出、切换、相对共同祖先比较、提交已暂存更改和显式推送指定远程的当前分支。变更动作先返回 60 秒有效、一次性预览；用户确认时重检 HEAD、分支引用、状态、暂存/未暂存差异与远程配置。拒绝带未提交修改的分支切换，不自动 stash、丢弃或 force。提交不自动暂存文件，推送不随提交自动执行。操作失败不自动重试。

Hg 保留当前分支和变更查看；本轮没有加入 Hg 写操作。实际提交、推送只会在用户点击确认后发生，测试使用独立合成仓库及本地 bare remote，没有修改或推送开发仓库。

## 插件接口

`runtime-src/desktop-environment/` 为独立 DSH 包。后端只注册原生 settings section；客户端使用 additive shell.overlay 和标题栏 utilities 插槽。没有新增模型工具或系统提示词。布局适配读取固定 DSH 版本的 frame/phase 标记，仅为对话正文设置可清理的 margin；不替换原生根布局或右侧栏。升级上游时应重新做宽窄窗口视觉检查。

## 验证

- 真实 DSH 浏览器：默认关闭、打开/收起、分支弹出菜单、现有/新会话、插件禁用及刷新保留、再次启用、深浅主题、900px 自动收起与留白清理。
- `tests/environment-repository.mjs`：真实 Git 状态、创建分支、脏工作区拒绝、过期状态拒绝、一次性确认、仅提交暂存区、比较分支、本地远程推送。
- `tests/desktop-workspace.mjs`：新会话 header、环境上下文、未跟踪子目录、跨源写请求拒绝。
- 最终构建结果见 `docs/evidence/environment-plugin-2026-09-22.json`。

### 自检结束状态修正

本轮完整构建暴露了自检完成状态与后台保存/额度释放之间的时序间隙：用户看到 COMPLETED 时，下一次启动仍可能返回正在运行。公开快照现在直到后台收尾结束才发布终态，落盘仍保存真实结果。增加延迟最终保存的确定性测试，验证收尾期间拒绝并发、完成后立即可启动下一轮。
