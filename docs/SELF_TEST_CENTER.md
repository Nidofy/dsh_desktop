# 自检中心

入口：Help → 会话诊断 → 自检中心。页面跟随 DSH 原生外观设置的明暗/系统模式和字号。打开、刷新、查看历史或导出都不会请求模型。引擎未能启动时仍使用桌面设置中的启动诊断和日志；本页依赖引擎运行。

## 两种检查

**本机自检**：18 项本机检查，在当前连接专属数据目录下创建随机隔离工作区，不操作用户工程，不加载用户规则或 Skills，不请求模型。

- 校验实际 Node 进程的路径、固定版本和官方 SHA-256；逐文件核对完整运行时（含 DSH 全部生产依赖）及实际文件集合；另核对桌面扩展与 Fixed WebView2 的专项清单。
- 原子存储读写、DSH 原生命令沙箱、真实文件写入/读取、原生文件系统 Skill provider 加载合成 Skill。
- Project Actions 未信任拒绝、受信固定操作执行和冷读、配置改变后失去信任；取消真实已启动的合成长命令。
- 在新建 Git/Hg 仓库中验证状态、基线及任务差异；未安装对应命令行时显示 SKIPPED。
- 产物旧引用失效、前缀分类、中断事件投影的持久冷读、通知去重/隐私、注入探针失败后停止后续请求。

**连接自检**：5 项连接检查，需选择模型并确认预算。使用当前连接的真实原生适配路径、凭据、代理、CA 和超时，没有故障转移到其他服务。

- 最多 5 次请求：4 次 2 KiB 合成缓存文本（两组各重复两次），再请求一次固定 echo 工具；模型输出不触发任何命令执行。
- 每次输出参数 64 tokens，总时限 180 秒，缓存阶段 120 秒，工具阶段最多 45 秒且受总时限约束；服务端仍决定实际计费及硬限额。
- 发出前准备并冻结请求配置，拒绝隐藏自动重试和过期连接指纹；每个请求前再次核对配置。失败停止缓存探针后续请求，工具检查按前置结果跳过。
- 验证请求完成、流式块、工具名/参数、缓存计数可见性和重复请求的正缓存读取。工具响应达到输出预算时为 UNKNOWN，不据此断言模型不支持工具。

另有两项始终保持 UNKNOWN 的现场验收：原生窗口/通知/真实异常恢复，以及企业网络观察。总计 25 项，按本次检查模式将未执行的项目标为 SKIPPED。

## 结果语义

| 结果 | 含义 |
|---|---|
| PASS | 仅该行明确描述的检查范围已验证 |
| FAIL | 实际执行失败或结果违背契约 |
| UNKNOWN | 缺少证据、输出预算不足、缓存未报告正读取，或需现场验证 |
| SKIPPED | 本次未选择、前置条件不满足、依赖未安装或取消后未执行 |

`COMPLETED` 表示检查流程结束，**不是全部 PASS**。页面显示四种结果的计数和固定排查建议。缓存字段来自 DSH 适配层；适配层可能补零，原始服务字段覆盖未知。未观察到正缓存读取不等于服务不支持缓存。

本机中断检查验证合成事件与持久状态语义，取消检查实际启动/终止隔离命令；不会故意杀死当前用户引擎。开发集成测试另外强制退出隔离引擎，验证自检持久记录能冷读为 INTERRUPTED 且不重放请求。现场休眠、断网、企业执行策略和真实工程仍需目标机验收。

## 存储与隐私

- 每连接最多一个正在运行的自检；页面关闭不会取消，可显式取消。退出引擎会中止自检；重启只读历史，不自动续跑。
- 执行前先持久化运行意图；每个检查后保存结果，保存失败停止后续工作。每份结果最多 64 KiB，保留最近 20 份。
- 仅自动清理本次新建、标记和 canonical 路径均匹配的隔离目录；异常退出遗留目录不猜测删除，达到 10 个遗留项拒绝继续创建。现可在设置页「本机存储管理」预览并显式清理身份标记匹配的遗留目录，见 [存储管理](STORAGE_MANAGEMENT.md)。
- JSON/Markdown 导出通过固定字段白名单重建，不包含工作区、服务地址、模型名、凭据、请求/响应正文、任意异常消息或实际会话 ID。固定范围说明、数值计数及可选 HMAC 配置指纹可保留。
- 自检请求不混入普通会话诊断采集，不注册模型可调用的“运行自检”工具，也不修改正常会话提示词。

完整性检查是对随包清单的本机校验，不是独立数字签名验证或完整供应链审计。逐文件范围、错误代码、构建和离线包检查见 [运行时完整性](RUNTIME_INTEGRITY.md)。

## 开发验证

```powershell
./runtime/runtime/node.exe scripts/sync-desktop-runtime.mjs
./runtime/runtime/node.exe tests/self-test.mjs
./runtime/runtime/node.exe tests/observability-wire.mjs runtime --self-test-only
# 需要已安装 Git，以及 .build/hg-test-venv 中的 Mercurial 7.2.2：
./runtime/runtime/node.exe tests/observability-wire.mjs runtime --self-test-only --self-test-vcs
```

真实引擎用例复用 Rust 测试生成的协议 fixture，两个协议都验证本机零模型请求、限定五次连接请求、取消、同源鉴权、隐私导出、正常重启与强制退出冷读。默认最小 PATH 同时验证 Git/Hg 缺失时正确跳过，附加参数验证真实 Git/Hg 路径。测试报告保存在 `.build/observability-wire-*`。

`tests/self-test-ui-preview.mjs` 是浏览器展示/交互 fixture，不能代替原生 Tauri 窗口验收。开发构建已接入自检单元与双协议回归。
