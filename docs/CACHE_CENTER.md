# 0.2.0 开发基线：缓存配置与合成验证

连接设置中的「缓存请求设置」管理实际请求策略，保存后通过现有切换/重启操作应用。Help → 会话诊断 →「缓存验证」提供按模型的能力声明、适配器行为说明、合成探针和本地结果。新页面跟随 DSH 原生明暗与字号设置，不修改主对话界面。

## 请求配置

| 选项 | 实际行为 |
|---|---|
| 原生默认 / 短期 | 显式固定官方 `cacheRetention=short`，保持原生短期行为，避免环境变量意外开启长期保留 |
| 自动缓存 | `cacheRetention=none`，不请求显式保留时间或标记；独立缓存键由下列选项控制，服务端是否自动缓存仍由服务决定 |
| 长期，OpenAI Completions | 请求 `prompt_cache_retention=24h`；键按独立设置控制，原生兼容模式保持旧的同时发送键行为 |
| 长期，Anthropic Messages | 原生 `cache_control` 增加 `ttl=1h` |
| OpenAI 格式的 Anthropic 标记 | 复用原生 `cacheControlFormat=anthropic`；只允许短期，需网关明确兼容 |
| 缓存键：原生兼容 | 保持捆绑适配器原行为，用于旧连接迁移 |
| 缓存键：关闭 | 删除 OpenAI 请求体中的 `prompt_cache_key`，保留时间/标记不变 |
| 缓存键：按会话生成 | 只为当前连接中明确勾选支持的模型生成 HMAC 键；未勾选模型或没有会话身份时不发键；不额外请求长期保留 |

新建连接的设置表单默认「自动缓存」与「关闭显式缓存键」。旧配置缺少缓存字段时按原生短期 / 原生键行为迁移。开启按会话键必须逐模型勾选确认支持；模型 ID 修改时清除确认，新模型不继承确认。保存后仍需切换 / 重启应用，不改变进行中的任务。参数被接受、正常返回或耗时降低都不能单独证明缓存已生效。

### 独立键的实现与升级约束

捆绑 DSH 未暴露 pi-ai 的公开 `onPayload` 请求钩子。桌面预加载器使用 Node 的模块加载钩子，**对固定版本适配器做两处内存源码扩展**：增加 `desktopCacheKey` 配置 schema，并把该配置接入 `streamSimple` 的 `onPayload`。没有改写磁盘中的 `node_modules` 或拦截全局 fetch；但这仍是需要维护和审计的上游适配补丁，不能称为完全未改动适配器。其他 provider、原生模式及 Anthropic 返回空扩展，保留既有路径。

- 唯一允许扩展的文件是 `@deepseek-ai/dsh-llm-pi-ai/lib/index.js`，SHA-256 为 `1f787eb5cd3d0308e7a2563cdb2b8cc2c1fc153fe06b55d39439fb2446059483`。原文 hash 或锚点不符时拒绝启动，桌面显示固定错误；升级 DSH 必须重新审查及运行门禁，不能自动忽略设置。
- 本机持久诊断密钥通过 supervisor 私有管道提供。独立键是带用途隔离的 HMAC，输入包含连接 home、endpoint、provider、协议、模型、会话 ID；输出固定 47 个 ASCII 字符。键不包含源码、提示或可读路径 / 会话 ID。只控制请求体中的键，不改写 SDK 的其他请求头。
- 同一会话的工具循环、多轮、重试与重启复用键；不同模型、连接、会话及探针 A/B 组分离。没有会话身份时不会退化为全局共享键。密钥只在构造流时读取，后续请求体处理不受可变配置影响。
- 重置诊断密钥、移动连接 home 或更换 endpoint 会改变键。凭据存储不可用而使用临时密钥时，缓存页明确提示重启不稳定；不承诺服务端 TTL、路由或 KV 缓存命中。
- 缓存页显示当前模式、模型范围及密钥持久性。适配桥版本进入诊断配置和能力声明指纹；桌面模块 SHA-256 清单覆盖桥接实现。

## 能力、配置和观察分开记录

- 按模型保存自动缓存、显式键、显式标记、长期保留四项 `unknown / supported / unsupported` 声明。来源固定为用户声明，不自动升级为验证成功；保存声明不会修改请求参数。
- 声明绑定当前连接目录、有效 provider 配置、凭据及代理环境的 HMAC 指纹；变化后显示过期。原始密钥、地址和代理信息不会进入该指纹输出。
- 探针单独记录适配器计数和结果，配置指纹再绑定所选模型；导出包含 key scope，跨 scope 不宜直接比对指纹。
- 若返回正缓存读取计数，结论为 `ADAPTER_REPORTED_CACHE_READ`；否则为 `INCONCLUSIVE`。原始 provider 计数覆盖始终 `UNKNOWN`，因为现有适配边界可能给缺失值补零。

## 合成探针

读取页面和能力信息不会发模型请求。用户选择模型、输入长度与请求数并勾选预算后才开始。API 同时检查同源、配置指纹和预算；准备期间配置变化也会在发请求前拒绝。

- 4 或 6 次请求；每次输入为 2、8 或 32 KiB ASCII 合成文本，输出参数为 64 tokens，总运行时限 120 秒。输入字节数不是计费 tokens；真正的计费和输出限制取决于服务。
- A、B 两组在前缀起始处分离，每组重复同一段文本；每次运行换随机前缀，避免沿用上次暖缓存。两组使用同一参数设置，是重复性探针，不是不同设置间的因果 A/B 实验。
- 通过 `ctx.llm.prepareCall().stream()` 走实际 DSH 适配器、凭据、代理/CA 和序列化路径。所有调用在开始前准备并检查零重试；不加载真实会话、工作区、规则、Skills 或工具。
- 不执行任何模型返回的工具，也不保存模型输出。记录状态、计数、首输出/总耗时和 HTTP 状态码。合成请求从日常对话诊断列表中排除，避免污染任务样本。
- 取消、超时、失败或结果无法保存时停止后续请求；已到达服务端的请求可能仍计费。服务端隐藏公共前缀可能让组内首条也报告缓存读取，不能把它当作分组失效的证据。
- 每连接保留最近 30 份结果，每份上限 64 KiB。运行前及每次请求后保存检查点；重启读取未结束记录时显示 `INTERRUPTED`，不自动重跑。
- JSON / Markdown 导出走现有受控下载入口，只输出允许的数值与状态，不包含模型名、地址、会话 ID、管理员声明正文、密钥或请求/响应内容。导出同样校验已保存字段，不盲目转发文件中的附加字段。

## 验证与边界

`tests/cache-probe.mjs` 验证预算、前缀/分组、取消/超时、零值不误判、输出不留存、导出白名单和落盘失败。`tests/cache-center.mjs` 验证只读入口、声明、凭据/配置变化、同源限制、重试拒绝及准备期间配置变化。

Rust 配置测试生成原生缓存策略夹具。`tests/observability-wire.mjs` 使用 OpenAI / Anthropic 的真实捆绑 DSH 适配器检查最终 HTTP：重复请求字节一致、组间前缀不同、无工程/工具上下文、自动模式无显式字段、长期和短期标记的具体字段、取消/重试拒绝、配置过期、强制退出不补跑。当前证据 `.build/observability-wire-3fE2AT`。

浏览器实测能力声明保存、过期提示、启动/完成、历史留存；真实 DSH 主题切至浅色和 17px 后页面跟随，背景为 `rgb(255,255,255)`。设置页测试替身验证选项保存、新连接默认自动模式与不兼容组合禁用；不把替身当作原生 Tauri 桥验收。

独立键新增 `tests/desktop-cache-key.mjs` 与 `tests/observability-wire.mjs runtime --cache-key-only` 构建门禁。真实 DSH + HTTP 验证仅键、键与长期保留、键与短期标记、长期但关闭键、未确认模型抑制、旧行为兼容、Anthropic 隔离、工具循环及重启稳定；证据 `.build/observability-wire-JObSic`。Rust 28 项及 Windows release 编译通过。设置页浏览器 fixture 验证逐模型确认 / 改名撤销、新连接默认和协议禁用，不代替原生 Tauri 桥验收。
