# 文件与产物

入口：Help → 会话诊断 → 文件与产物。项目操作页可打开当前工程的产物；任务恢复页可打开该会话的正式交付文件。页面跟随 DSH 的明暗主题、系统偏好和字号，不修改 DSH 主界面。

## 文件来源

1. **会话交付**：从 DSH 原生 `deliverables/presented` 事件投影读取，最多 100 个引用。冷会话也可读取，不激活 Agent、不发送 prompt。分叉继承的旧事件不算作本任务新交付。
2. **构建声明**：Project Actions 配置增加可选 `artifacts`，最多 20 个相对工作区根目录的精确文件路径，不是相对 action.cwd；不展开 glob。声明跟随具体执行记录保存，配置变化需要重新信任。最近 20 次运行的产物与日志合计最多显示 100 条。
3. **操作日志**：由当前连接的 Project Actions 服务解析已知运行记录，再定位自身日志目录；浏览器不能直接指定 DSH_HOME 下的任意文件。
4. **手动登记**：用户填写工作区和相对路径，登记已存在的本地普通文件。每连接持久保存最近 256 条，当前工作区显示最近 100 条。移走文件后记录仍保留并标为不可用，不删除原文件。

示例：

```json
{
  "schemaVersion": 1,
  "actions": [{
    "id": "test",
    "label": "回归测试",
    "command": "./run-tests.ps1",
    "cwd": ".",
    "timeoutMs": 600000,
    "artifacts": ["reports/results.csv", "reports/summary.md"]
  }]
}
```

构建声明只说明配置预计产出这些文件。文件可能预先存在、由其他进程更新或来自失败构建；页面保留运行状态，**不宣称是该次构建新生成，也不替代验收**。所有引用都指向当前文件，不是历史内容备份。

## 操作

- **打开**：复用 DSH 正式 `sessionController.openWorkspacePath`，支持明确列出的文档、文本和图片扩展名。可执行文件、脚本和其他未开放类型不直接启动。
- **所在目录**：复用 DSH 原生 reveal 操作。不会自行执行文件。
- **另存为**：使用已鉴权的本机专用导出参数，Windows 桌面调用原生保存对话框，支持选择位置、覆盖确认与取消。浏览器访问时沿用浏览器下载行为。

登记和列表本身不打开应用、不读取正文、不调用模型。操作前重新核对规范化路径及文件身份、大小和修改时间；过期或已改变的引用要求刷新。入口是随机标识，有效期 10 分钟，进程最多保留 512 个，不把任意路径放进下载 URL。

## 路径、另存与留存边界

拒绝 `..`、绝对文件路径、盘符流、设备名、仓库元数据路径以及含 symlink/junction 的子路径；仅允许本机工作区普通文件，或服务自己解析出的 Project Actions 日志。明示 UNC 根目录不支持。原生应用打开仍遵循本机文件关联，不能把扩展名白名单视为内容安全扫描。

另存单个文件最多 512 MiB，最多两条并发下载，总预留副本容量最多 512 MiB。请求先在当前连接的 `desktop-artifact-exports` 中制作临时副本，再发送下载响应；准备期间变化则拒绝。这样即使保存位置覆盖了源文件，正在传输的字节也来自已准备副本。下载完成/取消清理临时副本；意外退出遗留的本功能临时文件，在下一次下载时清理超过 1 小时的文件。磁盘不足或配额不足时拒绝下载，不改写源文件。

临时副本只服务一次另存，不是可恢复的任务快照。原生保存对话框使用 Windows 系统样式；应用页面使用 DSH 样式。

文件内容不进入去标识诊断导出，不自动上传。主 DSH 窗口继续拒绝通用下载；诊断窗口只开放既有诊断导出路径，新增 artifact 参数还需后端校验有效文件引用。没有开放远程 URL、任意文件下载或新的模型工具。

## 验证与剩余验收

- `tests/desktop-artifacts.mjs`：越界、设备路径、链接、类型限制、过期/文件变化、中文文件名、空文件、原字节下载、保存目标覆盖源文件、取消和临时文件/句柄释放、持久登记、投影边界及 Project Actions 信任关联。
- `tests/observability-wire.mjs`：OpenAI/Anthropic 真实 DSH `present` 工具调用与持久事件、构建声明/日志、鉴权/同源下载，以及既有缓存/恢复/工具回归。
- Rust 16 项测试通过，包括下载 URL 限定；Windows release 编译通过。测试不弹出保存对话框，也不实际打开用户应用。
- 真实 DSH 浏览器实例验证中文文件登记、可执行类型禁用「打开」、过期内容提示及跟随浅色 17px/深色 15px。测试只操作合成文件。

**未完成的现场验收**：Windows 原生保存对话框的实际选择、覆盖、取消、下载失败反馈；默认应用打开与 Explorer 定位；真实大型产物和内网策略环境。发布 stable 前必须补齐，不能用 HTTP/编译测试替代。
