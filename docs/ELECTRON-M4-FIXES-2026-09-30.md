# M4 桌面使用问题修复

本轮处理桌宠无法显示、环境浮窗缺失、个人联网版缺少官方登录，以及个人扩展和工程工作台切换选项卡、缩放后排布错位。沿用官方 `dsh-v0.2.0-rc.2` 基线，修复包单独位于 `electron/apps/desktop/.desktop-build/targets/win-x64/candidates/m4-fixes/personal-unsigned/win-unpacked`，原 M4 包保留。

## 操作入口

- 官方登录：主窗口左下角「更多 → 登录」。个人版仍可不登录进入本地工作区，退出账号不强制回到欢迎页。
- 环境浮窗：主窗口右上角「环境信息」。卡片跟随当前会话，显示工作区、仓库和分支，提供变更、构建、产物、快照、桌宠、连接入口；关闭卡片停止轮询。普通文件夹显示没有 Git/Hg 仓库的说明。
- 桌宠：环境信息 → 桌宠 → 显示桌宠；也可从应用 → 个人扩展 → 桌宠进入。「显示桌宠」同时开启总开关和所选实例；「添加实例」也开启总开关；「隐藏所有桌宠」关闭服务。
- 启动修复包：运行 `electron/migration/m4-fixes/launch-trial.ps1`。先退出旧包；脚本沿用 `m4-trial-data`，保留原连接、会话和偏好。验收脚本使用独立临时数据，不接触该试用目录。

## 原因与实现

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 桌宠不出现 | 已选实例启用，但 `pets` 总开关关闭；添加实例没有开启服务 | 增加明确的显示、隐藏操作；添加实例开启服务；保存和增删前读取最新修订，保留其他页面设置与桌宠位置 |
| 环境浮窗缺失 | 迁移只提供独立工程工作台窗口，遗漏工作区内入口 | 使用官方 `shell.overlay` 插槽添加客户端卡片；从会话查询服务读取当前目录；通过受限原生 IPC 打开对应工作区工具 |
| 登录入口缺失 | 个人版 overlay 同内网版禁用了账号插件，原生平台会话和账号订阅也被统一跳过 | 个人版恢复官方账号插件、账号订阅及平台会话；内网策略继续独立处理；遥测、反馈上传及自动更新策略维持关闭 |
| 缩放和选项卡错位 | 工作台对所有 input 设置最小宽度，复选框也被拉宽；长控件和 flex 子项不能充分收缩 | 复选框独立样式，表单与下拉框限制宽度，表格局部横向滚动，窄窗取消工作台粘性页头，个人扩展输入行与按钮按可用宽度换行 |

环境卡片、桌宠偏好与展示继续放在私有插件；主进程仅提供窗口和账号平台适配，不改 Agent Loop、模型请求格式或会话持久化格式。
