# DSHDesktop 0.2.3-rc.2 · 桌宠资源与多实例候选版

基于 0.2.0 正式版本，累计包含 0.2.1、0.2.2 桌宠能力。没有替换 0.2.0 交付目录，也没有自动提交或发布。当前构建与运行证据见 PETS-MILESTONES.md 和 evidence/pets-0.2.3.json（完成检查后生成）。

## 使用入口

运行独立交付目录中的 DSHDesktop.exe，在桌面设置 → 桌面宠物启用「吃白饭的大肥鱼」。默认关闭。每只宠物可拖动，单击进行互动、双击或点击任务气泡打开对应会话；右键菜单可固定当前会话、恢复自动跟随或隐藏实例。

设置页支持最多三个实例，各自选择资源、缩放、互动/观察开关、固定目标、位置重置、轻量心情和纯文本气泡。资源管理可选择 ZIP 或目录中的 pet.json，预检后导入；同 ID 替换需要勾选替换。删除正在使用的自定义资源会恢复内置宠物。导出目录由用户指定，生成独立 ZIP，不带连接或会话内容。

## 数据与兼容范围

- 只读原生结构化会话事件及 task-recovery 投影，最多缓存 32 个会话；所有实例共享宿主轮询，增量游标不连续或引擎变化时恢复完整快照。
- 任务状态、短暂反应、用户互动与心情分开；等待气泡保留、取消静默、子任务和冷读取不重复庆祝。完成只表示本轮结束。
- 标准 8×9、192×208 格及明确 v2 的 8×11 子集，参考与保存样例见 pets/compatibility/README.md。任意自定义 Codex 几何、未知版本和所有历史格式不在兼容承诺中。
- ZIP 上限 64 MiB、总展开 128 MiB、条目 256、JSON 1 MiB、累计解码 32 Mi 像素、单边 4096。预检校验实际解码、几何、帧数、时长、路径、重复项、链接和解压比例。仅安装归一化数据，不执行脚本。
- 本地心情 normal/happy/resting；有效互动每 60 秒最多增加 1 点亲密度，上限 100。关闭不累计、离线不扣分，心情只改变空闲表现，可随时重置。
- 宠物权限不包含文件读写、命令执行、审批或聊天；资源由宿主受控加载。生产 CSP 保持原约束。不改变模型请求或缓存前缀。

## 素材和验收边界

基础 v2 图集保持原图和校验，独立 pat/happy/dragged 图像及素材视觉记录已生成；被弃用生成帧单独注明。完整素材源在 assets/pets/xiaojing/extensions，生产包仅使用声明清单与必要 WebP。

自动化和原生进程验收不替代全部真实硬件体验。真实触屏/笔、跨 DPI 多屏拖动/拔屏、系统通知焦点体验、长期空闲性能仍应在实际使用环境验证。使用失败不得阻塞主程序；资源缺失回退内置素材。导入过程针对静态路径检查并限制读取，不声称抵抗拥有同用户写权限的攻击者在校验中并发替换路径的所有竞态。

RC2 移除宠物继承的全局应用菜单，修复高 DPI 下多余窗口高度；原生检查比较菜单句柄和客户区尺寸，不以 Tauri 保留的 WS_CAPTION 样式位误判可见标题栏。RC1 留存为过程候选，不再作为推荐入口。
