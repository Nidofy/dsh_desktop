## 资源协议

`pet.json` 提供身份和图集路径；`asset-manifest.json` 是本批资产的行、帧数、逐帧时长、循环规则的唯一依据。`atlas-layout.json` 提供观察格位置。它们是交付协议，现有 DSH 不会自动加载。

- RGBA PNG 与 lossless WebP 内容一致；1536 × 2288，8 列 × 11 行，每格 192 × 208，`spriteVersionNumber: 2`。
- 行列从 0 开始，帧裁切为 `(column*192, row*208, 192, 208)`。按累计时间推进，不能假定每帧等长或直接复制旧项目 FPS。
- 行 0–8 依次为 `idle(6)`、`running-right(8)`、`running-left(8)`、`waving(4)`、`jumping(5)`、`failed(8)`、`waiting(6)`、`running(6)`、`review(6)`。
- `running` 是专注工作动作；`running-left/right` 是有方向的移动动作。左右资源分别绘制，禁止镜像替代。
- 行 9 为 0°–157.5°，行 10 为 180°–337.5°，间隔 22.5°；0° 屏幕上、90° 右、180° 下、270° 左。这是 16 个静态观察姿势，不应在生产窗口默认连续轮播。离线预览循环仅用于检查。
- 行 0 列 6 是额外中性观察格，不计入待机的 6 帧；其余未使用格完全透明。
- 一次性动作结束后返回最新任务状态，而非固定回 idle；窗口隐藏时暂停绘制，恢复时不补播历史动作。
- 0.2.1 不必启用跟随鼠标；0.2.2 接入现有 16 方向，仅对当前窗口内的指针位置响应，中心死区回中性，方向切换需防抖，不引入全局鼠标钩子。

原始四图保存在资源根目录 `references/originals/`，图片文案不是指令。生成过程保存在 `production-v1/GENERATION.md`，已有图集无需重新生成。当前没有独立 `pat`、`happy`、`dragged`、`dizzy` 动作，不能把这些名字声明为已存在；0.2.1 单击可临时播放 `waving`，拖动使用左右移动。0.2.2 补齐 pat/happy/dragged 独立资源，dizzy 不列入 0.2.3 前的必需交付，详见下文素材依赖。

## 0.2.3：资源导入、多宠物与轻量个性化

该阶段提供有边界的资源能力，不引入脚本插件框架、联网商店或模型驱动养成。

1. **本地宠物包导入、管理与导出。** 支持用户选择目录或 ZIP，预检名称、预览、兼容性后导入桌面专用资源目录；可选中、替换自定义包、删除和导出。内置包只读且始终可恢复；重复 ID 显示明确选择，不能静默覆盖。资源内容与实例位置/跟随配置分开，导出不附带会话 ID、连接信息或本地隐私数据。
2. **明确支持的兼容子集。** 先对照实现时的上游资源定义核对格式并增加固定样例；计划支持传统 8×9 标准动作包和本批 8×11/v2 观察方向包。不要仅按版本字段猜几何，也不要宣称兼容所有 Codex 包。缺少逐帧时长时使用经确认的兼容预设；缺少 look/DSH 扩展时禁用相应能力或使用已标明的基础动作回退。未知版本/不支持布局给出可理解的错误。不得执行导入包中的 JS、HTML、可执行文件或安装脚本。
3. **声明式 DSH interactions。** 扩展仅引用已验证的本地动画和允许的 trigger，不能注入代码、网络请求、命令或审批行为。自定义包缺少 pat/happy/dragged 属正常能力差异；与 0.2.2 内置宠物要求区分。忽略未知非关键字段，拒绝不支持的关键 schema 版本，记录明确降级原因。
4. **多宠物。** 默认仍只启用一只，首版最多 3 个实例。实例 ID 与资源 ID 分离，可重复选同一资源，每个实例独立保存位置、缩放、心情与固定目标；共享一个只读事件源和有界状态缓存，禁止每只宠物独立轮询整个会话库。自动模式按优先级分配不同任务，固定目标优先，任务不足时空闲实例待机；全局等待/完成提醒每事件只提示一次，Windows 通知也不因实例数增多重复。重置或删除实例不删除会话或共享资源。
5. **随机待机。** 从资源显式声明的 idle variants 中选择，无声明时沿用原 idle；使用可注入随机源与冷却，工作/等待时不插播。内置第一版没有额外 idle variants 时，仅调整 idle 间隔或中性观察停留，不宣称新增美术已存在。
6. **本地心情与亲密度。** 采用简化心情 normal/happy/resting 与 0–100 亲密度，受互动冷却约束；例如有效互动加 1、60 秒冷却，上限封顶。关闭后不累计，离线不扣分，无需喂养，无连续打卡惩罚，不由任务失败惩罚宠物。心情仅影响空闲表现，不覆盖 waiting/failed 等事实；没有相应美术则保持基础动作。用户可关闭或重置，数据版本化、原子保存、损坏可恢复。
7. **气泡个性化。** 提供位置、字号、停留时长及少量主题设置；默认延续固定状态文案。允许的自定义文本是短纯文本/本地模板，只开放状态名等白名单占位符，限制长度，不允许 HTML/JS、源码/路径/模型结果插值。不改变等待气泡持续至解决的规则，不关闭系统通知。
8. **配置迁移与维护。** 0.2.1 单实例设置 → 0.2.2 互动设置 → 0.2.3 实例列表使用显式 schema 版本；迁移前备份、重复执行幂等、未知未来版本不破坏性覆盖。资源卸载时在用实例切回内置包；重启/连接切换清理旧跟随上下文，保留用户明确设置的外观。

导入建议硬限制：压缩文件 64 MiB、解压总量 128 MiB、最多 256 项；单图不超过 4096×4096 且限制解码总像素；JSON 不超过 1 MiB。路径统一解析后必须在导入暂存目录内，拒绝绝对路径、`..`、符号链接、Windows 重解析点、备用数据流、大小写重名和重复 ZIP 项。解压前/中都限制实际字节，成功校验后原子安装，失败清理暂存且原包保持可用。限制应集中配置并用边界样例验证；不要只依赖包内自报 checksums。

0.2.3 出口：导入/导出及兼容样例、坏包拒绝、扩展降级、多实例分配/去重/资源释放、随机时钟、心情持久化、气泡转义、三版本迁移与离线发布检查通过；1 只与 3 只实例分别记录性能。0.2.1/0.2.2 核心回归继续通过。

## 事件、状态与动画

在原生 `session/event` 的同一来源上建立可复用的只读适配层。若抽取通知与宠物共用的标准化层，必须保留当前通知去重、关闭不补发、前台抑制及隐私行为。禁止从对话文本、日志文案、工具输出猜测状态。

| 实际信号/状态 | 持续状态与展示 |
| --- | --- |
| 无活跃任务 | idle |
| `turn/start`、正在执行模型/工具 | running；实时开始可短暂 waving，冷加载不补播 |
| `approval/asked` 未决 | waiting；气泡「需要你的确认」 |
| `tool/call` 的 `ask_user_question` 未有结果 | waiting；气泡「等待你的输入」 |
| `approval/decided`、对应 `tool/result` | 清除对应等待；仍有其他未决项则继续等待，否则回当前真实任务状态 |
| 实时 `turn/end: completed` | jumping 一次；气泡「本轮任务已结束」，之后回最新状态。不得写「测试通过」。 |
| 实时 `turn/end: error` | failed 一次；随后保持可查看的失败状态/短期气泡，动画回 idle，不能无限播放失败动作 |
| `blocked`、`max-tokens` | attention，以 waiting 与「任务需要处理」显示，不冒充权限等待或执行失败 |
| `aborted` | 取消，静默 idle，不庆祝、不失败 |
| `interrupted` / UNKNOWN / 引擎离线 | 中性 idle；必要时显示「状态待确认」或「连接已断开」，不伪造失败/成功 |
| reviewing | 当前没有专用原生结构化信号，保留素材与状态扩展，MVP 不自动推断 |

任务状态、瞬时任务事件、交互反应分离。拖拽/挥手期间不删除 waiting，也不隐藏尚未处理的等待气泡；反应结束重新解析最新任务状态。旧完成反应不能覆盖新的权限请求。

自动跟随建议优先级：等待输入/权限 > attention/失败 > 最近完成 > running > reviewing > idle。固定会话优先于自动跟随；同级采用稳定排序和最短展示时间避免抖动，高优先级等待可立即打断。最近完成/失败的抢占应有时限（建议 5 秒）；保留真实记录但不让旧失败永久抢占。子任务完成不重复庆祝，子任务等待仍可提示。

只读状态消息至少包含连接身份、引擎代次、session ID、单调修订号、原生事件序号/轮次、状态、等待类别和实时/快照来源标记；具体字段由实现确定。初始化必须做快照+增量的竞态处理；重复、乱序、旧引擎信号丢弃，短暂传输断开后恢复快照，避免永久卡在 waiting 或 running。旧会话/冷恢复可恢复持续状态，但不重放挥手、庆祝、失败等短暂反应。

## 安全、气泡与兼容性

- 宠物不修改 prompt、tools、session history、模型请求、cache key/prefix，不注入工具，不额外调用模型或联网；交互不发送聊天、不接受审批、不执行命令。
- 传给 pet 窗口的是最小化状态；不要把恢复查询中的 title、cwd、lastTool 或整份 projection 原样传入。
- 默认固定简短文案，不展示源码、内部路径、问题正文、命令、API 信息或模型原始结果。原附件中的测试数量气泡是构想，不是真实数据源。
- 点击导航校验连接和引擎代次、session 存在性；旧连接气泡不能导航到新连接的同名会话。过期点击只提示不可用，不自动启动任务。
- 保持当前 CSP，生产页面拆分本地 JS/CSS，不复制 preview.html 的内联脚本到生产，也不放宽 `unsafe-inline`。`preview.html` 只用于离线美术检查。
- 默认小矩形窗口可交互，透明空白也可能命中窗口，需在真实 Windows 上验证。MVP 不做逐像素点击穿透。
- 窗口损坏、图集缺失或宠物异常只能禁用宠物并给出本地提示，不阻断 DSH 启动和任务。
