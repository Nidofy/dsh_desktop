# 吃白饭的大肥鱼 — 资源包 v1

基于用户提供的四张蓝鲸女仆形象参考图，以内置 imagegen 生成。正式显示名称由用户指定为「吃白饭的大肥鱼」，内部 ID 保留 xiaojing。

## 内容

- `spritesheet.webp` / `spritesheet.png`：透明 RGBA 图集，1536 × 2288，8 列 × 11 行，每格 192 × 208。
- `pet.json`：spriteVersionNumber 2 的基础资源描述。
- `atlas-layout.json`：16 个观察方向和中性观察格的位置。
- `asset-manifest.json`：9 组动画的行号、帧数、逐帧时长与循环建议，供未来 DSH 资源加载器使用。
- `portrait.png`：透明全身角色母版。
- `preview.html`：双击后可离线切换动作、背景和显示大小。预览为方便检查会循环播放一次性动作。

标准动画为 idle、running-right、running-left、waving、jumping、failed、waiting、running、review。第 9、10 行为顺时针 16 个观察方向，0° 向上，90° 向右，180° 向下，270° 向左。第 0 行第 6 列为额外的中性观察姿势，不计入六帧待机循环。其余空白格透明。

## 检查结果与边界

图集尺寸、透明边缘、空格、完整性和逐行动作检查通过；三位独立盲检者均正确辨认四个主方向；独立最终视觉检查通过。

已接受的轻微差异：112.5°、157.5°、292.5° 的其中一个方向分量较弱；157.5° 到 180° 的低头幅度略大；跑步是简化的伸展/收腿循环；轻跳角色比待机约小 6%。动作检查使用按时序解码的帧和时长，不是 DSH 原生窗口实测。

本包未安装到 Codex，未接入 DSH Desktop 0.2.0。格式检查不等于真实客户端安装或运行验收。`asset-manifest.json` 是资源交付协议，当前 DSH 不会自动加载它。

完成动作不表示测试通过；取消任务不应播放失败动作；review 在没有结构化任务信号时不自动绑定。任务、互动与短暂事件反应仍应分开。

摸头、开心、被拖拽等 DSH 专用独立互动动画不包含在这批 9 个标准动作中，列入 0.2.2 素材制作与验收；目前未完成。
