DSH Electron 本地便携版

将完整目录解压到较短的路径，再双击 Start DSH.exe。app 目录、resources、runtime 与启动器必须一起保留，单独复制 EXE 不能运行。

默认专用数据根为 %LOCALAPPDATA%\NidofyDSHPortable\data-v1。更新程序目录后仍使用这个数据根。第一次选择的专用目录必须尚不存在，由启动器创建；后续只接受带有效 nidofy-portable-data-v1.txt 标记的原便携数据根，不采用已有真实用户目录。不会注册协议或安装系统命令，产品沙箱保持开启。

可显式选择新专用绝对路径，例如：
"Start DSH.exe" --data-root=D:\DSHPortableData

不要移动或复制数据根来代替恢复，Notebook 依赖原物理文件身份。程序目录可替换，数据根须保持稳定。程序退出后再更换程序目录。

本包用于本地功能使用，未经签名，不含正式安装器。第一次打开连接设置后自行配置模型连接；侧边分析只有确认单次请求才发送，并单独统计用量。测试均使用本地合成提供方，不含真实 API key。

侧边分析：前台会话空闲时，在侧栏打开“侧边分析”，选择受管连接，输入选定文字，预览并确认。结果仅在侧栏显示；“追加结果到草稿”保留原文字、引用、附件与光标，绝不自动发送。关闭或切会话取消分析。连接需要零重试策略；输入最多 12 KiB、输出最多 2048 Token、180 秒超时；活动记录上限可在 1–20、归档上限可在 0–80 内明确预览确认，所有会话共享预算；容量或权限不足会拒绝新请求，金额未知。历史支持活动／归档筛选、查看原始请求结果、预览确认归档及原始记录本地导出。归档不删除原日志，导出包含私人文本，不调用模型或自动追加草稿。

有限设置：侧栏“用一句话设置”显示当前支持的本地指令。预览后确认，页面显示原服务实际回执。伙伴口吻默认关闭，启用或关闭从主会话下一回合生效，代码与正式报告保持正常风格。取消等待不能撤销原服务已提交的操作；回执不明时点击“读取当前设置”，查看当前会话口吻、所选桌宠和关注目标的只读快照，再决定是否明确新预览。读取失败撤下旧值，不自动确认、重试或请求模型。

桌宠：先从桌宠设置启用总开关，再在侧栏刷新已配置实例并选择绑定、解绑、静音或挥手。绑定为 Session 级关注。显示的启用、绑定和气泡静音是上次读取的状态，在其他地方更改后须明确刷新；读取失败撤下旧动作，等待操作时锁定目标选择和刷新。

Live2D：固定模型与用户提供的 Cubism SDK for Web 5-r.5（兼容 5.3）运行组件已包含。侧栏点击“启用本地 Live2D”后加载；隐藏时停止渲染，缺失资源或 WebGL 失败时回退静态立绘。不会调用模型、读取会话内容或运行任意模型脚本。当前仅播放 Idle 摆动；拆层接缝仍待美术精修。已完成真实 WebGL 和 100 次启停测试，记录了进程 CPU/内存检查点；GPU 显存峰值未观测，不视为已通过。包内保留 SDK 使用条件，本包不证明公开发行资格。
